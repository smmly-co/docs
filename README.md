# SMMly Documentation

Documentation home for the SMMly self-hosted SMM panel and its developer integrations.

> **Status: Initial documentation repository.** Only verified behavior will be documented as currently supported. Planned or unreleased capabilities will be labeled clearly.

## Documentation areas

- Product overview and terminology
- Installation and configuration guides, after deployment steps are verified
- Administration and customer workflow guides
- [API availability and release status](api/README.md); full API reference after the API is implemented and tested
- Integration guides and examples, after supported contracts are available
- Security, backup, upgrade, and troubleshooting guidance

## Source of truth

Do not treat a planned feature as released. Where documentation and the application differ, report the discrepancy rather than assuming either is correct.
