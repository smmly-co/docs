# SMMly API — Developer and Reseller Integrations

Connect your SMM business workflows with SMMly.

SMMly is building developer resources for agencies, social media marketing businesses, SMM panel operators and resellers that want to connect their own websites, applications, reseller panels, bots and server-side tools.

## Integration use cases

- Connect a customer-facing SMM website or reseller panel.
- Integrate service discovery and order workflows.
- Manage order information from connected business applications.
- Build internal tools and workflow automation around supported SMMly capabilities.
- Explore bulk and multi-order workflows where supported.

## API documentation and access

Official API documentation, authentication requirements, supported actions, request formats, limits and access information will be published here when available.

Do not rely on guessed endpoints or unofficial compatibility examples. Use only the current SMMly API contract and access details published by SMMly.

For product information, visit [smmly.co](https://smmly.co). For reseller information, see the [SMMly reseller guide](https://github.com/smmly-co/docs/blob/main/resellers/overview.md).
